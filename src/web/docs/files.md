# Files and editors

## Purpose
Filesystem shows capability-scoped files on the selected Device. File tabs are editors, not local copies of a remote workspace.

## Before you begin
Choose a context with filesystem capability and open Filesystem.

## Normal workflow
Browse folders, open a preview, pin a file you want to keep open, edit, and save. Unsaved changes are marked in the tab.

## What you will see
Preview tabs are reused for clean files. Pinned or edited tabs remain separate. Workspace roots can be pinned for quick access.

## Recovery
Save or discard edits before changing profile. If a file cannot be read or saved, check Device connectivity and permissions before retrying.

See also: [Workspace](atlas-doc:workspace) and [Profiles](atlas-doc:profiles).
