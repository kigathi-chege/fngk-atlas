# Workspace and panels

## Purpose
Atlas is a persistent workspace: panels can be arranged, minimized, restored, or closed without treating the application as a sequence of pages.

## Before you begin
Choose an available FNGK context from the left rail. Atlas restores a saved layout for that profile and context.

## Normal workflow
Open tools from the activity rail, command palette, contextual actions, or this guide. Drag tabs only into compatible workspace regions. Use minimize when you expect to return to a tool.

## What you will see
The left rail selects contexts and opens common tools. The center is the active workspace. Operations appear in the bottom dock. The filesystem and inspector occupy the right side when open.

## Recovery
If a panel is missing, use its activity-rail action or command palette command. A reset is unnecessary for a single missing panel.
