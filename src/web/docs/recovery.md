# Recovery and readiness

## Purpose
Device lifecycle makes FNGK readiness visible and offers the smallest safe repair action.

## Before you begin
Select the Device and profile you intend to repair. Read the diagnostic before changing anything.

## Normal workflow
Open Device lifecycle, identify whether login, pairing, operator authorization, daemon readiness, or an update is required, then use the presented repair action.

## What you will see
Readiness is reported as a state with diagnostics. It is not inferred from a successful Atlas page load.

## Recovery
Follow the specific diagnostic. Reconnecting Atlas does not replace signing in, pairing, authorizing, or starting the correct FNGK daemon.

See also: [Profiles](atlas-doc:profiles), [Devices](atlas-doc:devices), and [Terminals](atlas-doc:terminals).
